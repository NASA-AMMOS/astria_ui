#### Find images from a single sol

{APPNAME} offers a search view called `Sol` for simple, single-sol-centric image browsing. You can also view a single sol in `Search` if you want to perform an open-ended search or use more advanced search facets.

<b>Finding Images for a Sol using the Sol tab</b><br>
Select the `Sol` tab in the left side panel. Input the sol you want to find images for and then click the search button or hit enter to view search results. The sol input defaults to the highest sol found for all image products.

<b>Finding Images for a Sol using the Search tab</b><br>
Select the `Search` tab in the left side panel. Input the sol you want to find images for as the start and end values of the `Sol` facet on the left. Hit enter or click the search button in the `Sol` facet to view search results. The end value of the `Sol` facet defaults to the highest sol found for all images products.
