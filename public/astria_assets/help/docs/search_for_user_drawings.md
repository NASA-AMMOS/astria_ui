#### Search for user drawings

<b>Finding User Drawings using the Sol tab</b><br>
Select the `Sol` tab in the left side panel. In the `Filter` menu, select `Drawing` in the  `Object Type` dropdown. This will filter results to only show Drawing products. If the `Drawing` option is not listed, no drawings can be found that match the current sol and your other `Sol` tab filters.

<b>Finding User Drawings using the Search tab</b><br>
Select the `Search` tab in the left side panel. In the `Object Type` facet, select `Drawing`. This will filter results to only show User Drawings. If the `Drawing` option is not listed, no drawings can be found that match the current sol and your other `Search` tab filters. You can additionally filter the User Drawing results by using any of the other facets available in the `Search` tab. The `Drawing Text` facet can also be used to search the tile, text, and inserted text content of User Drawings.
