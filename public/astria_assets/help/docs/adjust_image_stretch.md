#### Adjust image stretch

Select the `Adjust` tab on the right side panel. Here there are multiple options for stretching an image. If available, you will see a histogram of the original image. All of the image stretches only apply to the base image and not to any of the overlays on top of it.

**Preview Mode**<br>
This is an image stretch done in the browser. This stretch mode operates on a pre-stretched image and does not use the full dynamic range of the image so many details of the image may be lost (such as rocks within shadows). To perform a stretch use the slider or enter new values in input fields and hit enter. When you select a new stretch it will override any previously applied stretch.

**Dynamic Mode**<br>
Dynamically stretches the source image. This mode is slower than Preview Mode but preserves all available detail. There are two ways to perform a dynamic stretch.

<i>Percent Stretch</i> - Enter the minimum and maximum percentile values for your stretch. The default stretch already applied to most images is 0.5% - 99.5%. You will see the default stretch in the input fields whenever your stretch is reset.

<i>Manual Stretch</i> - Enter the minimum and maximum data values for your stretch, or use the sliders. Next to the minimum/maximum value fields, you will see the max and min data values for the image. The default values you see in the input fields are the default stretch values already applied to the image you are viewing. You do not have to obey the min and max values here if you would like to stretch outside of the bounds of the image.
