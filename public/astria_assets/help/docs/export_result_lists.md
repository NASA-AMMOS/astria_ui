#### Export result lists

Export a subset of metadata from various result lists within {APPNAME}. This includes search results and related imagery subtabs. Click on the download button next to the number of results to open the export modal. Only the currently loaded pages of image results will be included in the metadata export. Export options include OCS URLs, filenames, {APPNAME} URLs, PNG/JPG image URLs, and a JSON file with a subset of OCS metadata included. For the full set of metadata you should refer to the actual product in {APPNAME} or OCS.
