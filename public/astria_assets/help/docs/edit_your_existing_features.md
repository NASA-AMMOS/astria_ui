#### Edit Your Existing Features

From the `Features` tab you should see an edit button next to each drawing you created. You cannot edit drawings that belong to others. Click the `edit` icon to begin editing a particular feature. This will open the `Image Feature Editor`.

Within the `Image Feature Editor` you can modify the feature keyword, geometry, confidence level, and notes just as you would when first creating the feature.

You will not be able to add additional geometries to this feature tag. If you want to mark additional areas you will need to select `Add Feature` from the `Features` tab.

Once you are done editing, click `Save Feature` to save your latest changes.
