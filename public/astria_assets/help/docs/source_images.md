#### View Source Images for Mosaics and Reconstructed Products

The {APPNAME} Source Images panel will list the images used to create a given mosaic or reconstructed image.

To find the images used to construct a product, do the following:

1.  Open a mosaic or a reconstructed image from any of the search tabs on the left.
2.  Click on the `Related` tab on the right side of the application and then click on the `Source` subtab.
3.  All input images for the base image will be listed below.

<b>View Source Image Bounds</b><br>
To view the bounding boxes of each source image in a mosaic, click on the `Show Bounding Boxes` toggle. The bounding boxes will appear on top of the mosaic. Click on a bounding box to filter the source image list to that specific image.

<b>Filter Source Images by IDX</b><br>
Filter the list of source images to just the image providing a given pixel by placing a data cursor. The list will filter to the image that was used for that pixel. Note that an IDX product is required.

<b>Viewing Associated Mosaics for Selected Image</b><br>
To view mosaics associated with your selected image (via bounding box selection or data cursor filtering) you can open the `View` option and toggle on `Show Mosaics Associated with Selection`. The associated mosaics will appear in a section below the filtered image list.
