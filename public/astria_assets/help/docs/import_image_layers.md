#### Import image layers

Add image overlays from {APPNAME} URLs, S3 paths, and filenames. With a base image already loaded, click on the three dot menu to the right of the active overlays header within the `Layers` tab and select "Add Layers From URL or Path". Add multiple layers at once by inputting a comma separated list. You can specify combination of Marsviwer URLs, S3 paths, and filenames in this list if desired. One helpful way to generate these lists of files for import is through exporting result lists in {APPNAME}.
