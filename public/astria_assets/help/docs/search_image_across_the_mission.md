#### Search images across the mission

Select the `Search` tab in the left side panel. From this search view you can perform open-ended searches across a variety of facets. For example, if you want to search for <i>All single-frame Navcam images from sol 20-25</i> you would enter 20 and 25 into the `Sol` facet, hit enter or click the search icon in the `Sol` facet, select `EDR` from the `Object Type` facet, and finally select `Navcam Left` and `Navcam Right` from the `Instrument` facet. Keep in mind that there are often multiple ways to accomplish a particular search. If you are familiar with the filename and instrument IDs, for example, you could replace the `Navcam Left` and `Navcam Right` part of the query with an `N` filename query which will target all filenames starting with `N`. While Navcam mosaics also begin with `N`, we’ve already excluded those by selecting `EDR` in the `Object Type` facet.
