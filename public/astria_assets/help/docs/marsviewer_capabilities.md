#### {APPNAME} Capabilities

<b>Fast, facet based search</b><br/>
Quickly search for single frame images, mosaics, quicklooks, {APPNAME} user uploads, and {APPNAME} user drawings across the entire mission. Use a variety of facets to progressively narrow down your search.

<b>High-priority mosaic browsing</b><br/>
Browse through the top mosaics across the entire mission to efficiently build context. Use your browser's text search (ctrl/command + f) to jump around to different points in time based off the displayed attributes of the mosaics such as sol, site, drive, and description.

<b>Image viewing</b><br/>
View images of any size including very large mosaics. These images will load in your browser at only the resolution needed. You can zoom all the way in to see the actual pixels at full resolution. Think of it like Google Earth and how it only loads as much data as is needed at that zoom level since you can’t download the entire world of data onto your computer.
Control zoom level, image rotation, image smoothing, and more.

<b>Metadata viewing</b><br/>

- View the metadata of the image and associated RDRs
- View the image VICAR label
- View science intent metadata
- Image Data Explorer (DN Cursor in Desktop {APPNAME})
- Get underlying data values for a pixel for any base image or associated overlay

<b>Drawings</b><br/>
Create drawing layers to mark up images using powerpoint-like tools. Share these drawings with others. Browse drawings for a single image or across the entire mission by annotation title, description, author, and added text content.

<b>Mark Image Features</b><br/>
Mark areas of an image with Science Intent Keywords. Share these features with others. Browse features for a single image or across the entire mission by keyword, confidence level, and author.

<b>Image upload</b><br/>
Upload images and PDFs to share them with others. You can tag these images with a sol, instrument, and description.

<b>Image download</b><br/>
Download single frame images and mosaics in IMG or PNG format. Download RDRs in IMG (and PNG format when available). Download quicklooks and user uploads in their original formats.

<b>Measurements</b><br/>
Measure XYZ distances when XYZ data is available.

<b>Scale</b><br/>
View scale information when RNG information is available. View rough scale information for Cylindrical mosaics based off of the camera model.

<b>RDR viewing</b><br/>
Overlay multiple RDR products (XYZ, RNG, Arm Reachability, etc) on top of your base image. Control RDR layer opacity and ordering.

<b>Tactical target viewing</b><br/>
Overlay 2D and 3D point targets, Az/El targets, and Proximity targets. View metadata for specific targets and open targets in ASTTRO and CAMP.

<b>Image stretching</b><br/>
Dynamically stretch images from their source data to view fine details. Perform rough but fast stretches using pre-stretched data to brighten an image.

<b>URL sharing</b><br/>
Share what you see in {APPNAME} with others. For complete reference on what goes in the URL, refer to the FAQ.

<b>Orbital context view</b><br/>
Understand the orbital spatial context surrounding an image.

- Visualize the rover location and orientation at the time of image acquisition on top of an orbital basemap
- View the orbital image footprint if one exists
- View the rover traverse and RMC waypoints
- Control click on the map for an estimated line/sample position within the current image
- Visualize the image data cursor within the current image on the map if stereo data is available at the selected line/sample position
- Open the RMC or lon/lat position in CAMP

<b>Application customization</b><br/>

- Draggable sidebars.
- Various search, image viewing, and preferences are saved to your browser's local storage.
