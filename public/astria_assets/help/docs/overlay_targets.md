#### Overlay Targets

Select the `Targets` tab on the right side panel to view available targets.

**Available Targets**<br>
Each target displayed in {APPNAME} meets the following criteria:

- The target must match the site and drive of the active base image.
- The target must be positioned within the bounds of the base image.
- The target type must be 2D Point, 3D Point, Az/El, or Proximity. No other target types are currently supported by {APPNAME}. Also note that {APPNAME} can only display Az/El targets on cylindrically projected mosaics.

**Interacting with Targets**<br>

- To show all listed targets in the image viewer, click the "Show All" button in the targets tab.
- To hide all listed targets from the image viewer, click the "Hide All" button (which previously said "Show All").
- View metadata for a target by clicking on the target in the list, clicking the info icon for the target, or clicking on the target in the image viewer.
- Focus the viewer on a target by clicking on the crosshairs icon for the target in the list.
- Open a target in ASTTRO by clicking the ASTTRO logo for the target in the list. You can also accomplish this from the target metadata view.
- Open a target in CAMP by first opening the metadata for the target and then clicking on the CAMP link.
- Open the image that a target was created on by opening the metadata for the target and then clicking on the link next to the "Image" label. This will open the image in a new {APPNAME} tab.

**Differences between Targets in {APPNAME} and ASTTRO**<br>

- {APPNAME} does not support all target types.
- {APPNAME}'s target display is read-only and not meant for planning purposes.
- ASTTRO uses different icons for targets in the image viewer depending on whether or not the target was originally made using the current base image. {APPNAME} uses a single icon for targets regardless of this information.
