#### Search for quicklooks

<b>Finding Quicklooks using the Sol tab</b><br>
Select the `Sol` tab in the left side panel. In the `Filter` menu, select `Quicklook` in the `Object Type` dropdown. This will filter results to only show Quicklook products. If the `Quicklook` option is not listed, no Quicklooks can be found that match the current sol and your other `Sol` tab filters.

<b>Finding Quicklooks using the Search tab</b><br>
Select the `Search` tab in the left side panel. In the `Object Type` facet, select `Quicklook`. This will filter results to only show Quicklook products. If the `Quicklook` option is not listed, no Quicklooks can be found that match the current sol and your other `Search` tab filters.
